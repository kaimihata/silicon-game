# Ready supersession and decision record

This record applies only to the proposed new production foundation. It does not change the browser spike.

| Decision | Production rule | Earlier behavior intentionally superseded |
| --- | --- | --- |
| Engine | Unity `6000.3.23f1`, URP, pure C# domain | Static browser architecture |
| Outcomes | Seeded discrete per-unit inspection/test results at 10 ticks/s | Fractional expected-count production |
| Logistics | Directional finite belts, visible items, per-port buffers, splitters/mergers | Bidirectional route-connectivity graph and aggregate flow |
| Design graph | Multiple components and actual path reachability/capacity | One part per family, exactly three required links, at most one express link |
| Thermal placement | Every compute touches shared-capacity 2×1 spreader | One thermal part merely adjacent to one compute |
| Rejection | INS and TST produce physical rejects | Assembly and packaging fractional reject categories |
| Sourcing | Explicit purchase quantities, lots, finite receiving | Automatically initialized 1,200-attempt inventory |
| Production trigger | Complete input sets drive each configured machine | Aggregate time/rate advancement |
| Recipes | Universal stage templates deterministically compiled from each immutable published design revision; seeded stages emit exactly one pass or reject | Submitted global design profile and universal CP-110/MD-110 recipes |
| Contract | Full lifecycle, reassignment, exactly 1,000 shipped units | Single static browser contract counters |
| Fixed endpoints | Free preplaced receiving, shipping, and unlimited scrap endpoints | Purchasable/movable prototype docks |
| Internal production | Preview only in Milestone 2 | Optional browser Thermal Forming Cell |
| Starting cash | Buffered material recommendation + reference capital + 15% | `$12,000` prototype constant |
| Balance | `$100` sale price, `$51` default BOM, `$30` operation, `0.9333` expected yield, `$86.78` expected accepted cost, `13.22%` contribution | Prototype values were exploratory and not a complete procurement economy |

Current full-game direction remains authoritative where this bundle is silent. No deferred full-game system is implied by the vertical-slice implementation.
